# Passport Alliance: ICANN for AI Agents

The internet works because it has a shared naming system.  
Autonomous AI does not.

Domains have DNS.  
Websites have TLS certificates.  
Humans have IDs.

AI agents have **nothing equivalent.**

That gap is dangerous — and it is getting wider every day.

## The problem

Modern AI agents can:
- call APIs,
- access data,
- move money,
- control infrastructure,
- run inside enterprises,
- and act on behalf of real people.

Yet there is no universal way to answer four basic questions:

1. **Who is this agent?**  
2. **Who authorized it?**  
3. **What is it allowed to do?**  
4. **Can we revoke it instantly?**

Without answers, autonomy becomes risk.

## What Passport Alliance provides

Passport Alliance creates the **identity layer for autonomous systems.**

It does for AI agents what ICANN did for the internet:

- A shared root of trust  
- A common registry  
- Independent issuers  
- Verifiable credentials  
- Decentralized adoption  
- Centralized legitimacy

We do **not** control every agent.  
We coordinate the trust system that makes agents accountable.

## How it works (simple model)

1. **APIS (the technical standard)**  
   The Agent Passport Issuance Standard defines what a valid agent identity looks like.

2. **Issuers (like Certificate Authorities)**  
   Multiple organizations can mint passports — universities, enterprises, governments, and platforms — but only recognized issuers appear in the public registry.

3. **The Registry (like DNS root)**  
   A signed, tamper-evident catalog of legitimate issuers.  
   Anyone can mirror it. Only the Alliance can sign it.

4. **Verifiers (apps, APIs, platforms)**  
   Systems decide which issuer tiers they trust — just like browsers trust certain certificate authorities.

## Why this matters for universities

Universities are rapidly deploying AI agents for:
- research automation,
- tutoring,
- grading assistance,
- campus IT,
- data analysis,
- and operational tooling.

Passport Alliance gives them:
- clear audit trails,
- accountable delegation,
- instant revocation,
- and cross-campus interoperability.

In practice, this means:
> “We know exactly which agent did what, under whose authority, and we can shut it off immediately.”

## Why this matters for enterprises and government

Autonomous agents will touch:
- financial systems,
- critical infrastructure,
- medical workflows,
- defense networks,
- and classified environments.

Passport Alliance makes this possible **without chaos** by binding every agent to a responsible principal and a cryptographic identity.

Only Passport Alliance can confer legitimacy.
